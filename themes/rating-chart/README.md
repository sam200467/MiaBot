# B50 + N10 + P50 分表主题

这是正式使用的 3600×1800 本地渲染主题。`renderer` 直接使用 `assets/overlay.png` 作为最终静态底图，不会改动底图中的高斯模糊或其它设计。

## 目录职责

- `renderer/`：程序实际执行的 HTML、CSS、JavaScript。
- `assets/`：程序运行时必须打包的图片。
- `design/`：PSD、背景和设计过程文件，不打包。
- `examples/`：供设计和调试参考的数据样例。
- `previews/`：预览输出和历史视觉对照图。
- `tools/`：离线预览脚本。
- `../shared/fonts/`：B50 与未来单曲主题共用字体。

## 本地预览

在项目根目录运行：

```powershell
node .\themes\rating-chart\tools\render-preview.js
```

默认输出为 `themes/rating-chart/previews/ongeki-theme-preview.png`。预览脚本会把临时数据写入 `renderer/preview-data.js`，渲染结束后删除。参考数据快照保存在 `examples/preview-data.js`。

## CSS 实时调试器

双击项目根目录的 `启动B50P50模板CSS调试器.bat`；如果中文文件名启动不便，也可运行 `start-rating-theme-css-editor.cmd`。

- 左侧编辑正式的 `renderer/theme.css`，右侧使用完整 B50 + N10 + P50 数据即时预览。
- 支持常用规则跳转、10%–100% 缩放、适应窗口、刷新预览和放弃未保存修改。
- 点击“保存到 theme.css”或按 `Ctrl+S` 才会写入磁盘。
- 调试服务仅监听 `127.0.0.1`；关闭启动窗口或按 `Ctrl+C` 即可停止。

## 正式接入字段

玩家信息来自 `GET https://u.otogame.net/api/game/ongeki/profile`：

- `userName` → 玩家名
- `level + reincarnationNum × 100` → 玩家等级
- `playCount` → 总游玩次数
- `lastPlayDate` → 最后游玩时间
- `avatar` → 自定义头像；为空时使用 u.otogame 默认音击头像

## 已落实的渲染规则

- B50、N10、P50 均按“先横向、再纵向”排列。
- 卡片底色与谱面难度一致。
- AB 时只显示 AB，不重复显示 FC；FB 可与 AB 或 FC 同时显示。
- B50、N10、P50 均值固定显示三位小数；N10 显示 `接口值 × 5 → 接口值`。
- 歌曲标题使用白色字；玩家名与总 Rating 使用渐变填充和描边。
- ID 框使用随主题打包的 `FOT-学参丸ゴ Pro`。
- 曲绘、头像或本地图片加载失败时中止生成并返回具体错误。
- `Generated by` 使用输入数据的 `generatorName`，缺省为 `MiaBot`。
